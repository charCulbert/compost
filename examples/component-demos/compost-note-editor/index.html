Editor 1/16 · snapping · 2 bars

Drag a note to move it, its edges to trim either end, Alt-drag (or press and hold) for velocity, drag on empty grid to marquee-select, double-click to add, draw mode to paint. The loop bar drags from either end or the middle. Delete, arrows (Alt for more), Cmd-A, Cmd-D duplicates one span later, Cmd-L loops to the selection, Cmd-Q quantizes. Wheel scrolls pitch, Shift-wheel time, Cmd-wheel zooms. The playhead is a position the host supplies.
