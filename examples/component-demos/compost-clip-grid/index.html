Host stopped

Two tracks of clip slots. A launch queues the clip until the next quantization point — the demo plays host, runs a clock and sets states back — then the progress washes behind the name. The stop slot takes the track out the same way. Drag a name to another slot or the other track (Alt copies); the grid reports the drop and the host moves the data. Double-click opens, right-click asks for a menu, F2 renames.
