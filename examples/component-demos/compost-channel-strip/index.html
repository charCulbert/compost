Column Meters running

The column is the channel. Drag anywhere up or down to set gain, sideways to set pan; the axis is picked from the first movement. Alt, Shift or a second press drags fine; double-click resets gain (Alt: pan); type a number to set it. The wash, the 0 dB notch and the meters share one dB axis, so a level that meets the wash edge is at unity. Levels come from setLevels() and emit nothing.
